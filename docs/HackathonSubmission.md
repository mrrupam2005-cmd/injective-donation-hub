# 🏆 Hackathon Submission - Injective Voting Arena

## Executive Summary
**Injective Voting Arena** revolutionizes Cosmos ecosystem governance with a dark futuristic cyberpunk UI, glassmorphism visual hierarchy, real-time vote metrics, and CosmWasm smart contract enforcement.

## Tech Stack
- **Frontend**: Next.js 15, React 19, TypeScript, Tailwind CSS, Framer Motion, Lucide Icons, React Hot Toast.
- **Blockchain & SDK**: Injective Protocol, CosmWasm Rust, `@injectivelabs/sdk-ts`.
- **Wallets**: Keplr, Leap, MetaMask, Ninji.

## Value Proposition
Replaces dull transaction portals with an engaging, interactive governance command center designed for high community retention and transparent decision-making.
